
# Vantage — лендінг для архітектурної студії

**Vantage** — це адаптивний лендінг для студії архітектури та інтер’єрного дизайну.  
Проєкт зосереджений на точній верстці, типографіці, адаптивному дизайні та плавних анімаціях.

## 📌 Опис проєкту

Цей проєкт є багатосекційним маркетинговим сайтом, створеним з використанням **HTML5 та CSS3**.  
Він демонструє вміння працювати з макетом, адаптивною версткою та візуальною ієрархією.

Дизайн коректно працює на **десктопах, планшетах і мобільних пристроях** та використовує CSS-анімації для покращення користувацького досвіду без JavaScript-фреймворків.

---

## 🎯 Основні можливості

- Повністю адаптивний дизайн (desktop / tablet / mobile)
- Чиста та структурована CSS-архітектура
- Media queries для різних розмірів екранів
- Плавні hover- та load-анімації
- Сучасний мінімалістичний UI
- Галерея проєктів та блок сервісів
- Чітка типографіка та візуальна ієрархія

## 🎨 Анімації

Анімації реалізовані за допомогою **CSS keyframes**:

- `scale-up-center`
- `scale-down-center`
- `rotate-center`
- `slide-in-bottom`

Використовуються для плавної взаємодії з елементами та покращення UX.

---

## 📱 Адаптивність

Верстка оптимізована під такі екрани:

- **Десктоп:** 1440px+
- **Планшет:** 768px – 1023px
- **Мобільний:** 430px – 767px

На кожному breakpoint:
- змінюються розміри тексту
- перебудовується layout
- коригуються відступи
